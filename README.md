# Cuadro a cuadro, pensando el mundo

Sitio web educativo para el proyecto interdisciplinar de Filosofía + Educación Artística de la IED Santa Bárbara, Bogotá.

## Contenido

La web presenta las siete fases del proyecto:
1. Identificación y planificación
2. Investigación teórica
3. Propuesta narrativa y audiovisual
4. Guion literario
5. Guion gráfico / Storyboard
6. Producción y posproducción
7. Resultado final, reflexión y sustentación

También incorpora el protocolo de uso responsable de IA, parámetros técnicos de Stop Motion, entregables, seguimiento y cierre/licenciamiento.
